# Security policy

## Supported versions

Only the latest published minor of `tryck` receives security fixes. While the major is `0`, a fix ships as a patch on that minor.

## Reporting a vulnerability

Report it privately through [GitHub's vulnerability reporting](https://github.com/willzys/tryck/security/advisories/new), not in a public issue or pull request. Include the version, your runtime and TypeScript versions, and the smallest code that reproduces it.

You can expect an acknowledgement within a week. Once a fix is released, the advisory is published with credit to the reporter unless you ask otherwise.
